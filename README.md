# E-Commerce Sales Analysis

An end-to-end data analytics project focused on analyzing e-commerce sales data using **Python, Pandas, MySQL, and Power BI**.

## Project Overview

This project covers the complete data analytics workflow, starting from data cleaning and exploratory data analysis to SQL-based analysis and interactive Power BI dashboard development.

## Tools & Technologies

* **Python** – Data cleaning, preprocessing and EDA
* **Pandas** – Data manipulation and analysis
* **MySQL** – Data storage and SQL analysis
* **Power BI** – Interactive dashboard and visualization

## Project Workflow

**Raw Data → Python Data Cleaning → Exploratory Data Analysis → Clean CSV → MySQL → SQL Analysis → Power BI Dashboard**

## Key Analysis

* Total Sales
* Total Orders
* Average Order Value
* Sales by Category
* Sales by Product
* Sales by City
* Monthly Sales
* Payment Mode Analysis
* Order Status Analysis
* Cancelled Orders
* Cancellation Rate

## Dashboard

The Power BI dashboard provides an interactive overview of e-commerce sales performance and order-related metrics, helping identify sales trends, product performance, customer payment preferences, and order-status patterns.

## Objective

The main objective of this project is to demonstrate an end-to-end **Data Analyst workflow** by transforming raw e-commerce data into meaningful analysis and business insights.
